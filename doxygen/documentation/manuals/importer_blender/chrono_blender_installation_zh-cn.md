安装 Chrono Blender {#chrono_blender_installation}
==========================

1.  你的电脑上必须安装一份 [Blender](http://www.blender.org) 软件。支持版本 3.4 或更高版本。

2.  打开 Blender。

3.  转到菜单 编辑/首选项...，然后点击 **插件** 选项卡
    
    ![](http://projectchrono.org/assets/manual/blender_install.jpg)

4.  点击 Install...（安装）按钮，然后在 Chrono 源代码中选择文件 chrono/src/importer_blender/chrono_import.py，接着点击 Install add-on（安装插件）。

5.  在插件列表中勾选以启用 Chrono 导入器插件。

6.  关闭 Blender 首选项窗口。

如果一切顺利，现在你将在每次启动 Blender 时看到一个额外的菜单 **文件/导入.../Chrono_import**。

阅读入门文档请参见 [Chrono::Blender](@ref introduction_chrono_blender) 页面。
