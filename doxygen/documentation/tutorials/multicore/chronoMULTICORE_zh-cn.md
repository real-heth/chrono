Chrono MULTICORE 模块教程 {#tutorial_table_of_content_chrono_multicore}
================================

Chrono 分发版包含多个用于多核模拟 Chrono 系统的演示，使用 [MULTICORE 模块](group__multicore__module.html)。

选定的演示：

- demo_MCORE_ballsNSC
- demo_MCORE_mixerNSC - 使用 NSC（非光滑）接触公式的简单示例
- demo_MCORE_ballsSMC
- demo_MCORE_mixerSMC - 使用 SMC（光滑、罚函数）接触算法的简单示例
- demo_MCORE_friction - 滚动和旋转摩擦示例
- demo_MCORE_motors - 使用线性和旋转电机的示例
- demo_MCORE_callbackNSC
- demo_MCORE_callbackSMC - 使用自定义回调进行接触报告的示例
- demo_MCORE_custom_contact - 用户定义碰撞对的示例
- demo_MCORE_particlesNSC - 使用同质球形粒子容器的示例，每个粒子只有 3 个自由度（无旋转）
