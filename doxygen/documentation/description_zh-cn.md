简介 {#introduction_chrono}
==========================

以下是 Chrono 的主要特性简要列表。

### 物理建模

-   刚体支持。
-   柔性体支持 - 包括 ANCF 和共旋非线性有限元分析。
-   支持流固耦合问题，通过 Chrono::FSI 模块。
-   库仑摩擦模型，捕捉粘滑现象。
-   支持滚动摩擦和旋转摩擦。
-   支持通过两种方法处理摩擦接触：互补方法和惩罚方法。
-   弹簧和阻尼器具有非线性响应。可以由用户定义。
-   大量关节和约束：球形、旋转、棱柱、万向、字形、螺旋、斜齿和直齿轮、滑轮等。
-   单向约束。
-   约束用于施加轨迹，或强制在样条、曲线、曲面等上运动。
-   约束可以有极限（例如肘部）。
-   约束可以是非定常的，也可以是完整的。
-   线性电机的自定义约束。
-   气动缸的自定义约束。
-   电机的自定义约束，包括减速器、学习模式等。
-   动态激活/停用约束。
-   简化的一维动力学模型。例如：动力传动系统、离合器、制动器等。有关更复杂的模型，请参见 Chrono::Vehicle 模块。
-   所有物理对象可以具有任意数量的“资产”，用于定义可视化形状、自定义属性等。

### 求解器
-   用于索引 3 微分代数方程的 HHT 求解器。
-   用于大摩擦接触问题的辛半隐式欧拉一阶求解器。
-   用于处理大摩擦接触问题的速度-冲量级求解器。
-   处理冗余/病态约束。
-   稳定化或投影方法以避免约束漂移。
-   静态分析求解器。
-   逆运动学和交互操作。

### 碰撞检测特性

-   支持球体、立方体、凸几何体、三角网格等的复合体。
-   由 Bullet 碰撞检测引擎提供的额外碰撞支持，该引擎被封装在 Chrono 内部。
-   广义相位碰撞检测：扫描和修剪 SAT。
-   狭义相位碰撞检测：AABB 和/或 OBB 二叉体积树。
-   包含自定义图元到图元回退机制的细节阶段。
-   对象周围的安全“包络”。
-   报告穿透深度、距离等。
-   物体可以被激活/停用，并且可以选择性地进入碰撞检测。

### 实现细节

-   基于 Eigen 的矩阵和向量操作。
-   针对向量、四元数、矩阵的优化自定义类。
-   针对坐标系和坐标变换的优化自定义类。
-   所有点/速度/加速度的操作都基于四元数代数。
-   特殊的归档引擎，具有简单可靠的持久化/瞬态序列化。
-   可扩展的运行时类工厂。

### 其它

- 基于模板的车辆建模（通过 Chrono::Vehicle）
- 通过 Python 脚本进行操作（Chrono::Python）
- 导入 STEP CAD 文件以定义复杂几何体
- 使用 Irrlicht 或 VSG 进行运行时可视化
- 使用 POV-Ray 或 Blender 进行后处理可视化
- 基于 CMake 的构建系统（跨平台，支持 Windows 64 位、Linux、MacOS）。
